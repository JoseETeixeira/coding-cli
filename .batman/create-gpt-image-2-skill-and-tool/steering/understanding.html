03
Verified API facts

GPT Image 2 has sharp boundaries

Supported

  • Direct generation and one-or-many-image editing.
  • png, jpeg, and webp base64 outputs.
  • low, medium, high, and auto quality.
  • Flexible sizes up to 3840 px per edge within pixel and aspect constraints.
  • Optional masks, moderation setting, compression, and multiple outputs.

Must fail clearly

  • Transparent background requests.
  • Invalid size multiples, pixel count, or aspect ratio.
  • Bad or oversized edit inputs and mask mismatch.
  • Missing key or organization verification.
  • Moderation-blocked user errors; no blind retry.
Operational constraint: complex prompts may take up to two minutes. Host tool timeouts must be intentionally larger than the current 60-second default.
