03 · Target flow

Reference → align → sample → inspect → classify.

Each layer produces named evidence. Any failed critical frame keeps overall status pending.

Proposed verifier

Skill composes; project remains authority.

New local skill owns generic comparison procedure. DCC, engine version, renderer, gameplay camera, asset spec, and specialist still define concrete commands and acceptance.

01Open supplied source; record exact image, clip, frame, and intended view.
02Align camera/FOV/aspect and name transform spaces before comparison.
03Capture max(2, ceil(source frames / 30)) distributed frames including endpoints, then add all critical frames.
04Inspect silhouette, contacts, occlusion, clipping, twist, volume, sliding, drift, and seam.
05Record every sampled-frame result; keep reference, runtime, and owner gates separate.
